# 计导期末复习 · 计算导论与程序设计（数组 → 类的设计）

## v2.1.1

精选题库共 414 题。11 个知识块各有 3 道四星题和 2 道五星题，可在「精选题库」先选知识块，再按星级筛选。本次新编 51 题，连同 v2.1 的 4 道高星题共 55 题。每道新题均含参考程序、解题提示、易错点及评测用例。

16 套模拟卷各从专题题库选入一道不同的高星压轴题，沿用各卷原题量、时限和分值。原压轴题按原编号移入精选题库。新版压轴题使用独立编号和作答记录。构建时会逐块、逐卷核对星级数量。

## v2.1

精选题库 347 题，模拟卷 16 套，知识精讲 11 节。原有四星和五星题统一调为三星。

每道新增题均配有样例与补充检查点。P17 只需实现 `points` 和 `count`，评测时自动加入裁判主函数。

核查表含171个条目，每条至少两道练习。V-题与原题共用算法，属于配套代码分析，不是第二道独立编程题。详见《知识点覆盖核查表.md》《四套期末仿真卷_试题册.md》《四套期末仿真卷_参考答案.md》《修订验证记录.md》。覆盖依据为本地课程资料，不代表学校所有可能命题。以下原版数量保留用于追溯，以本段和网页动态统计为准。

北京邮电大学 大一上《计算导论与程序设计》**期末机考（C 语言）**离线复习网站的单文件网页版。

- 在线预览：<https://umtairitsusama.github.io/jidao-final-review/>
- 直接打开仓库里的 `index.html` 可以离线复习和记录作答。浏览器评测加载编译器时需要联网。

在作答栏用「语言」选择 C11 或 C++17，选择随题保存。两种语言均支持自测、提交评测和 VS Code 语法高亮。提交后弹窗逐项显示实际输出、标准输出和得分。「问题」面板列出可点击定位的编译诊断，「终端」面板显示编译与运行输出。

浏览器内的评测使用 Clang/WASI，支持 C++ 标准库。本机评测可运行 `python tools/local_judge.py --open`，默认使用 GCC/G++，可通过 `--cc`、`--cxx`、`--flag` 和 `--cxx-flag` 对齐 VS Code 的编译任务。此入口只在回环地址提供，仅适用于自己信任的程序。

## 构建与验证

```sh
python build.py --out index.html
python tools/check_problems.py --all
node tools/ui_test.mjs index.html
node tools/ui_test.mjs index.html --judge
```

源码位于 `app/`（template.html / style.css / app.js），题目数据位于 `content/`，写作规范见 `SPEC_FINAL.md`。
旧版页面地址（`library.html`、`exams.html`、`exam-m1.html` …）会自动跳转到对应的新视图；本机存储键仍为 `cd_review_v2`，旧记录继续可用。
